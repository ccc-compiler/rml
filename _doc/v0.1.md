# RML v0.1

作者：Claude（v0.1 by claude）

這個版本是 RML 編譯器的初始版本，將 ML-like 的函數式語言 RML 編譯成 Rust 程式碼。

## 概述

RML v0.1 是一個單檔編譯器（`rmlc.rs`，約 1960 行），採用 Rust 實作，不依賴外部 crate。編譯流程為：

1. **詞法分析（lex）**：將原始碼 token 化
2. **語法分析（parse）**：建立 AST
3. **Hindley–Milner 型別推論（HM type inference）**：自動推論型別
4. **所有權／移動檢查（move/ownership checking）**：檢查使用後移動（use-after-move）等所有權錯誤
5. **Rust 程式碼產生（codegen）**：產生可編譯的 Rust 程式碼

## 建置

```bash
rustc -O rmlc.rs -o rmlc
```

目前 repo 已經包含預先編譯好的 `rmlc` 二進位檔。

## 使用方式

```bash
./rmlc prog.rml [-o out.rs] [--run] [--stdout]
```

- `-o/--output <file.rs>`：指定輸出的 Rust 檔案（預設為 `prog.rs`）
- `--run`：產生 Rust 後自動呼叫 `rustc -O` 編譯並執行
- `--stdout`：將產生的 Rust 程式碼輸出到標準輸出，而非寫入檔案

## 語言特性（v0.1）

- **函數式語言核心**：`let`、`let rec`（頂層遞迴）、`fun`、模式比對 `match with`
- **型別系統**：Hindley–Milner 型別推論、代數資料型別（ADT）、泛型（type variables `'a`）
- **內建型別**：`int`（i64）、`float`（f64）、`bool`、`unit`、`string`（String）
- **代數資料型別**：`type` 宣告，可定義多建構子（含遞迴型別）。內建 `list`（`Nil | Cons of 'a * 'a list`）與 `option`（`None | Some of 'a`）
- **模式比對**：支援 `Nil`、`Cons`、tuple、建構子、wildcard `_`、常數模式等
- **運算子**：整數與浮點數分別有自己的算術運算子（`+ - * / mod` vs `+.-.*./.`）、字串串接 `^`、比較、邏輯運算子 `&& ||`、賦值 `:=`、變數更新 `<-`
- **參考與可變性**：借用 `&`、可變借用 `&mut`、解參考 `!`、可變綁定 `let mut`
- **所有權檢查**：move 語義、使用後移動（use-after-move）偵測、不可變／可變借用規則、閉包捕獲處理、`clone` 內建函式
- **尾遞迴優化**：頂層尾遞迴函式會被轉換成 Rust `loop`（見 `sum_to` 範例）

## 內建函式

編譯器提供一組極薄的 runtime 函式（inline）：

- 輸出：`print_int`、`print_float`、`print_string`、`print_endline`、`print_newline`
- 字串轉換：`string_of_int`、`string_of_float`、`string_length`、`concat`（透過 `^` 運算子）
- 型別轉換：`float_of_int`、`int_of_float`
- 數學：`sqrt`、`abs`、`min`、`max`
- 其他：`clone`

## 範例程式

`examples/` 目錄包含多個範例：

- `fib.rml`：遞迴與尾遞迴（`sum_to` 使用尾遞迴轉 loop）
- `lists.rml`：ADT、模式比配、高階函式（`map`、`fold`）、借用
- `tree.rml`：遞迴型別（二元搜尋樹）、自動 boxing、所有權沿樹流動
- `ownership.rml`：move、借用 `&mut`、`clone`
- `err_use_after_move.rml`：展示使用後移動的錯誤情境

執行所有範例：`./run.sh`（會對每個範例執行 `./rmlc examples/<name>.rml --run` 並顯示尾端輸出）。

## 實作細節

- **Closure 捕獲**：函式值（`fun`）在 move 語義下處理捕獲的變數
- **遞迴型別**：遞迴欄位自動使用 `Box` 來避免無限大小
- **主程式包裝**：產生的程式碼會將使用者 `main` 包裝成 `rml_user_main()`，並在獨立執行緒中以 1GB 堆疊執行（避免深遞迴／長鏈結串列的 stack overflow）
- **保留字處理**：Rust 關鍵字會自動加底線避免衝突；型別名稱會做首字母大寫等調整

## 已知限制（v0.1）

- 區域 `let rec` 尚未支援（必須將遞迴函式放在頂層）
- 不支援部分套用（currying）
- 資料型別欄位不支援函式或參考（函式／參考僅能作為值使用）
- 某些型別約束（如 Clone/PartialEq/PartialOrd）會在需要時加入 trait bound
